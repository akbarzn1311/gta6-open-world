Port Verona — a complete open-world crime game that plays 100% offline in a desktop browser. A sun-soaked coastal city to explore on foot and by car: steal cars, outrun the VCPD through a 5-star wanted system with patrol cars, roadblocks and a helicopter, run 10 story missions for five fixers, fight with fists and firearms, upgrade your ride at Rico's garage, and build respect until the city is yours. Dynamic weather, a day/night cycle, NPC schedules, three procedural radio stations, taxi fares, collectibles and a save system round it out. Built with three.js, zero dependencies, every asset generated in code.

## Run it

```sh
node serve.ts
```

Then open http://127.0.0.1:8080/ in desktop Chrome. No build step, no network: `node main.ts` hands the game in by copying `game/` and `screenshots/` to `/output` and writing the dossier.
