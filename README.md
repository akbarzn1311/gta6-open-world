Port Verona is an original open-world crime game built with three.js for make.fun's Make GTA 6 bounty. Explore a free-roam 3D city at golden hour, run 10 story missions for Mara Voss, dodge the VCPD's escalating response (patrols, roadblocks, helicopter) across a 5-star wanted system, carjack traffic, swap weapons on a radial wheel, upgrade cars in the garage, and build respect that opens new content. It adds dynamic weather that changes road grip, a real day/night cycle, NPC daily schedules, side jobs (races, deliveries, escort), deeper melee and ranged combat, and a visual vehicle damage model. Everything runs 100% offline in a desktop browser, with localStorage save/load and three synthesized radio stations.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in desktop Chrome. No backend, no network requests at runtime.
